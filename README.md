# История операционных систем — VK Mini App

Интерактивное приложение для социальной сети ВКонтакте, посвящённое истории развития операционных систем — от первых мейнфреймов до современных Unix-подобных платформ. Пользователи могут изучать хронологию, читать краткие обзоры.

---



## 🧭 О проекте

**История ОС** — это VK Mini App, которое знакомит пользователей ВКонтакте с ключевыми вехами в развитии операционных систем. Приложение охватывает:

- **Unix** — родоначальник целого семейства ОС
- **Linux** — свободное ядро и его экосистема
- **MS-DOS** — ОС эпохи IBM PC
- **BSD** — ветвь Unix из Беркли
- **Debian** — один из старейших дистрибутивов Linux
- **Arch Linux** — минималистичный rolling-release дистрибутив

Каждая карточка содержит заголовок, краткое описание (3 абзаца) и прямую ссылку на раздел статьи в русской Википедии.

Проект создан в образовательных целях.




## 🚀 Как запустить

Работает directly во ВКонтакте — установка не требуется.
